# FrappeForge

Open-source developer tooling for the [Frappe Framework](https://frappeframework.com)
and ERPNext ecosystem — libraries, SDKs, and utilities that make building on Frappe
from modern JavaScript and TypeScript stacks simple, safe, and predictable.

FrappeForge is an independent community organization. It is **not affiliated with,
endorsed by, or maintained by Frappe Technologies**. "Frappe" and "ERPNext" are
trademarks of Frappe Technologies Pvt. Ltd.

## What we do

We build and maintain the pieces that sit between a Frappe site and the applications
that talk to it: API clients, type generators, framework integrations, and the tooling
around them. Every project here follows the same standards:

- **TypeScript-first.** Strong types, generated from your own DocTypes where possible.
- **Minimal dependencies.** Small, auditable packages that do not drag in a runtime.
- **Runs everywhere.** Node, browsers, workers, and edge runtimes, without forks.
- **Stable and documented.** Semantic versioning, changelogs, and a published API surface for every release.
- **Boring by design.** Predictable behavior, explicit errors, no hidden network calls.

## Get involved

- **Questions and ideas:** open a discussion or issue in the relevant repository.
- **Contributions:** every repository has a `CONTRIBUTING.md` describing how to get set up and what we expect from a pull request.
- **Security:** report vulnerabilities privately through the repository's security policy — never in a public issue.
